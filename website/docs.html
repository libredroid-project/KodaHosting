Documentation

Everything you need to host a Minecraft server from your phone.

Getting started

  1. Download the latest APK from GitHub Releases and install it (allow "install unknown apps" for your browser).
  2. Open KodaHosting and accept the Terms of Service. The first-start tutorial walks you through the basics.
  3. Tap the + button, choose a name, server software and version, and create the server.
  4. Tap START. On first start the app downloads the server jar and the required Java runtime — this needs internet and a few minutes.
  5. When the server shows ONLINE, share the join address shown on the dashboard. Friends connect through the KodaHosting tunnel — no port forwarding needed.

Java runtimes

Each server can pick its own Java version: 8, 17, 21 or 25. Auto mode picks a sensible default per software (Fabric servers get Java 21, everything else Java 25). Runtimes download on demand on first start — no manual setup.

Modpacks (Fabric)

Open the Plugins/Mods tab → search Modrinth → pick a modpack → install. KodaHosting downloads the pack, resolves dependencies, verifies checksums and applies server-side overrides automatically. Player-side mods stay on the players' clients.

Console & files

  • Console tab: live server log with colors and a command input (like a real server console).
  • Files tab: full file manager — browse, edit (text files), import/export, rename, copy, delete. Binaries like jars open as downloads, not text.
  • Crash screen: 40+ known crash causes are detected automatically with a suggested fix. For anything unusual, tap Ask AI — the AI reads the last 1000 log lines and explains the cause and fix in your language.

Network budgets

Server Settings → Network Rules. Create rules like "1 GB mobile data per week" or "20 GB WLAN per week" and choose what happens when a limit is reached: warn, stop the server, or block starts until you are on a network where the rule doesn't apply. The dashboard shows live usage with a traffic-light bar and current speed. Mobile rules never affect you while on WLAN.

Battery & background hosting

Android aggressively limits background apps. KodaHosting asks once to disable battery optimization — accept it for reliable 24/7 hosting, especially on Xiaomi/MIUI devices. The tunnel uses fast heartbeats so idle connections don't drop.

FAQ

Can my friends join from Bedrock (phone/console)?

Yes on PumpkinMC servers (Bedrock is built in) and on Paper/Purpur servers with Bedrock support enabled at creation (installs Geyser+Floodgate automatically).

Does hosting cost money?

No. It runs on your own device. The optional AI crash assistant uses a free-tier AI endpoint and is rate limited.

Why did my server suddenly go offline?

Check the console: the app tags tunnel events with timestamps. Most common causes are Android background limits (see battery section) or device storage being full.

Where are my worlds?

Files tab → world/. Use "Export as ZIP" in server Settings for backups before big changes.

Is my data private?

See the Privacy Policy. In short: server data stays on your device; Supabase stores account/status metadata; the AI assistant only sends data when you explicitly tap Ask AI.
