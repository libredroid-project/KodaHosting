Everything a server needs

🧱

All server software

Paper, Purpur, Folia, Vanilla, Forge, Fabric, NeoForge — and PumpkinMC, a native Rust server that boots in under a second with built-in Bedrock support.

🛠️

One-tap modpacks

Search Modrinth directly in the app and install Fabric modpacks with dependency and checksum handling — no file juggling.

☕

Pick your Java

Per-server Java 8, 17, 21 or 25 runtimes, downloaded on demand. The app picks the right one automatically when unsure.

📶

Network budgets

Set data rules like "1 GB mobile per week" and the app enforces them — warn, stop or block starts when the budget runs out.

🤖

AI crash assistant

40+ known crash causes are detected with built-in fixes. For anything else, ask the AI — it reads the last 1000 log lines and explains the fix.

🌍

Tunnel & crossplay

frp tunnel with fast heartbeats keeps players connected, and Bedrock players join via built-in crossplay on supported servers.
